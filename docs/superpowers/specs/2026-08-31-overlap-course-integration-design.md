# 重叠课程整合与直接编辑设计

## 背景与问题

当前应用在“同一节次、不同周次”存在多门课程时，用户体验存在明显断点：

- 开启“显示非本周课程”后，重叠课程可以显示出来，但点开课程详情只能看到第一门课，无法直接编辑另一门。
- 不开启该选项时虽然可以新建课程，但重叠关系又不可见，用户被迫“先关、建完、再开”。
- 学校课表经常把同一门课按周次拆成多条记录，例如“自然语言处理 4-5,8-11周”与“6周”分开显示。
- 同名课程在不同周次可能更换老师或教室，例如“形势与政策5”在 13/14/15 周分别对应不同老师与教室。

用户参考超级课程表的交互，希望同一时段存在多门逻辑课程时：

1. 默认显示非本周课程。
2. 课程块上有重叠角标。
3. 点击后弹窗列出该时段所有课程。
4. 弹窗内可以直接编辑已有课程，也可以直接新建同节次课程。
5. 自动整合被拆分的课程记录。

## 目标

- 让“显示非本周课程”开启时也能直接新建和编辑同一时段的课程。
- 在周课表网格中为重叠时段提供可见角标。
- 重叠课程弹窗按“逻辑课程”展示，而不是按数据库原始行展示。
- 保存时自动合并完全相同的拆分记录，避免数据越存越碎。
- 保持现有“一个课程名下多个方案”的编辑模型。

## 非目标

- 不直接解析 `.xls` 教务导出文件。导入能力后续单独设计，但会复用本文的归一化逻辑。
- 不改变现有课程名称、周次选择、颜色、自定义时间等基础编辑能力。
- 不做数据库结构迁移；所有整合均在业务层完成。

## 术语

- 逻辑课程：同一课表内，课程名、星期、节次/时间段相同的课程集合。它可能对应数据库中的多条 `Course` 记录。
- 课程方案：一条 `CourseScheme` 或数据库中的一条 `Course` 记录，包含老师、地点、周次等信息。
- 重叠时段：同一星期的同一时间段内存在两门及以上逻辑课程。

## 数据与展示规则

### 保存时合并

在 `AddEditCourseViewModel.onSave()` 中新增归一化步骤。使用以下稳定键分组：

```text
name + day + isCustomTime
+ startSection/endSection 或 customStartTime/customEndTime
+ teacher + position
```

规则：

- 同一组内只保留一条 `Course` 记录，周次取并集。
- 若组内存在多个 `dbId`，保留第一个，其余在保存时删除。
- 同课程名但老师或地点不同，保留为不同方案，不合并。

归一化工具放在独立文件，例如：

```text
shared/src/commonMain/kotlin/com/xingheyuzhuan/shiguangschedule/data/model/CourseSchemeNormalizer.kt
```

### 展示时归并

在 `WeeklyScheduleViewModel.mergeCourses()` 中，对同一重叠簇内的课程按“逻辑课程键”分组：

```text
课程名 + day + 归一化后的起止时间
```

规则：

- 同一逻辑课程的多个数据库行渲染为一个课程块。
- 块内的周次展示为所有方案的周次并集。
- 不同逻辑课程仍按现有子列布局并排显示。
- 重叠角标数量按逻辑课程数量计算，而不是数据库行数。

## 组件设计

### 1. 周课表重叠角标

- 在 `MergedCourseBlock` 和 `ISingleSchedulable` 上增加重叠数量字段。
- 在 `CourseBlock` 右上角绘制纯数字角标，只显示被折叠的课程数量，例如“2”。
- 数量大于 1 时显示；只有一个逻辑课程时不显示。
- 角标补充无障碍描述，例如“另有 2 门课程”。

### 2. 重叠课程弹窗

改造 `CourseDetailBottomSheet`：

- 数据源从“数据库原始行”改为“逻辑课程分组”。
- 每页展示一门逻辑课程：
  - 课程名。
  - 合并后的周次。
  - 老师/地点：若所有方案相同则单行展示；否则按方案逐行展示。
  - 星期与节次/时间。
  - 备注。
- 每页保留编辑按钮，点击后进入该逻辑课程的编辑页。
- 弹窗底部新增“添加同节次课程”按钮。

### 3. 新建同节次课程

- 在 `WeeklyScheduleScreen` 中构造 `PresetCourseData`：
  - 继承当前重叠块的星期与节次/自定义时间。
  - `presetWeeks` 默认为当前周。
  - 其余字段留空，进入添加课程页后由用户填写。
- 点击后关闭弹窗并导航到 `AddEditCourse`。

### 4. 默认显示非本周课程

- 将 `AppSettingsModel.showNonCurrentWeekCourses` 默认值从 `false` 改为 `true`。
- 设置页保留原开关。
- 已保存过 `false` 的用户保留其现有选择，不做强制迁移。

### 5. 手势编辑兼容

由于同一逻辑课程可能对应多条数据库记录，长按拖动或调整高度时，应将该逻辑课程下的所有记录一起应用时间变更。在 `WeeklyScheduleViewModel` 中新增批量时间更新入口，`WeeklyScheduleScreen` 改为调用批量入口。

## 数据流

```text
数据库 Course/CourseWeek
    -> getCoursesWithWeeksByDate / getCoursesWithWeeksByTableId
    -> mergeCourses：重叠聚类 + 逻辑课程归并
    -> MergedCourseBlock(overlapCount, clusterCourses)
    -> ScheduleGrid：子列布局 + 重叠角标
    -> CourseDetailBottomSheet：逻辑课程分页
    -> 编辑/新建 -> AddEditCourseViewModel.onSave()
    -> CourseSchemeNormalizer 合并 -> upsertCourse
```

## 错误处理

- 归一化键中任一时间为空时，跳过该方案并保留原样，不抛异常。
- 逻辑课程分组后若代表性课程不存在，回退到原始列表。
- 批量手势更新时逐条处理，任一条失败只影响该条，不影响整体页面。
- “添加同节次课程”无当前周上下文时，回退为全学期周次。

## 测试与验证

- 用用户提供的课表数据构造用例：
  - 同一门课拆分的多条记录合并为一条。
  - 同名异老师/地点的记录保留为多方案。
  - 重叠时段角标只显示数字，且数量正确。
  - 弹窗按逻辑课程分页且可编辑。
  - 弹窗内可直接新建同节次课程。
- 为归一化工具补充纯逻辑测试（若项目测试基础设施允许）。
- 执行 `./gradlew :androidApp:assembleDebug` 确认可构建。

## 未来扩展

- 解析学校导出的 `.xls`/教务数据，并复用 `CourseSchemeNormalizer` 自动整合拆分项。
- 在重叠课程弹窗内直接预览周次分布，或在网格中提供更细的周次视觉提示。

## 风险

- 逻辑课程归并会影响网格布局与手势行为，需要重点回归长按拖动、高度调整、浮动调课。
- 保存时合并记录会改变既有数据的行数，需要确保删除逻辑只作用于当前课程名范围。
- 默认开启“显示非本周课程”可能让已有用户看到更多课程块，属于预期行为变化。
